# Лабораторная 3: файлы в PR

В пул-риквест должны попадать **только** файлы, нужные для проверки:

| Файл | Зачем |
|------|--------|
| `main.py` | Чтение CSV, валидация regex, вызов checksum |
| `checksum.py` | MD5 по номерам невалидных строк (из шаблона курса) |
| `result.json` | Вариант и контрольная сумма для GitHub Action |
| `77.csv` | Персональный CSV (скачать с Drive курса, **не коммитить** если политика репо запрещает — тогда только локально) |
| `.github/workflows/result-check.yml` | CI (если workflow лежит в корне монорепо — один раз на репозиторий) |

**Не добавлять в PR:** дубликаты `main.py` / `checksum.py` внутри `.github/`, лишние `README` в подпапках, вложенные `.github/.github/`.

Локальный запуск:

```bash
cd msdt-3
python main.py
```
