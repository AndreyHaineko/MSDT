# Лабораторная 7 — асинхронный пайплайн данных

## Что делает код

Файл `LR7.py` — **конкурентный ETL-подобный сценарий** на `asyncio`:

1. **Extract** — функция `fetch_from_source`: параллельно «качаем» данные из 5 источников.
2. **Transform** — функция `process_record`: параллельно обрабатываем каждую полученную строку.
3. **Load (вывод)** — `main` печатает итоговый список.

Ожидание сети/обработки имитируется через `await asyncio.sleep(...)`, как в лекции по async I/O.

## Схема

```
Источники 1..5
      │  asyncio.gather(fetch_from_source × 5)
      ▼
  [сырые строки]
      │  asyncio.gather(process_record × 5)
      ▼
 [обработанные строки] → print
```

## Запуск

```bash
cd msdt-7
python LR7.py
```

В консоли будут пометки `[fetch]` и `[process]` — видно, что задачи идут параллельно (время ~3–5 с, а не 5×3 последовательно).
